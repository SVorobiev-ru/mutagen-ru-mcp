# Безопасность

Проект неофициальный и не связан с Мутагеном (mutagen.ru). Здесь — уязвимости самого `mutagen-ru-mcp`. Проблемы сервиса Мутаген сообщайте Мутагену: support@mutagen.ru.

## Поддерживаемые версии

До версии 1.0 исправления выходят только в последней версии `0.x`.

## Как сообщить об уязвимости

Не открывайте публичный issue. Напишите приватно одним из способов:

- GitHub: вкладка Security → «Report a vulnerability» в репозитории [SVorobiev-ru/mutagen-ru-mcp](https://github.com/SVorobiev-ru/mutagen-ru-mcp/security/advisories/new);
- почта: mail@svorobiev.ru.

Опишите, что можно сделать, как воспроизвести и какие версии затронуты. Не прикладывайте свой ключ API, логи с ключом и личные данные аккаунта. Ответим в течение 7 дней. После исправления опубликуем advisory и, если хотите, укажем вас как автора находки.

Что считаем уязвимостью:

- ключ API попадает в лог, текст ошибки, кэш, журнал задач, выгружаемый файл или ответ MCP;
- обход защиты от трат: бюджета, режима «только бесплатное», подтверждения сметы;
- двойная оплата одного и того же запроса из-за ошибки клиента;
- запись файла `save_as` вне `MUTAGEN_OUTPUT_DIR` в режиме `--http`;
- доступ к HTTP-серверу MCP без токена, когда токен обязателен.

## Если утек ключ Мутагена

1. Перевыпустите ключ в кабинете: https://mutagen.ru/?api_config. Это первое и главное действие.
2. Включите там же «Разрешить подключение только с ip» и оставьте только свои адреса.
3. Проверьте баланс и массовые задания: `mutagen-ru balance`, `mutagen-ru mass list`. Незнакомые траты — повод написать в support@mutagen.ru.
4. Уберите ключ из места утечки. Если он попал в git, одного нового коммита мало: ключ остается в истории. Считайте его скомпрометированным (шаг 1 уже сделан) и при необходимости перепишите историю.
5. Обновите ключ везде, где он используется: `.env`, конфиги MCP-клиентов, секреты CI.

## Что важно знать о ключе

- API Мутагена работает только по HTTP: ключ уходит по сети открытым текстом в адресе запроса. Белый список IP в кабинете — главная защита.
- `mutagen-ru-mcp` берет ключ только из переменной `MUTAGEN_API_KEY` и заменяет его на `***` во всех сообщениях, логах и файлах.
- Держите ключ в `.env` с правами `600`, в секретах CI или в хранилище MCP-клиента (`${input:...}` в VS Code, `${env:...}` в Cursor и Windsurf). Не коммитьте конфиги с ключом.
