Мутаген для нейросетей. `mutagen-ru-mcp` — MCP-сервер для [Мутагена](https://mutagen.ru): Claude Code, Claude Desktop, Codex, Cursor, VS Code, Windsurf и другие MCP-клиенты получают частоты Вордстата, хвосты, конкуренцию, отчеты Мега-инструмента и готовые сценарии: «собери ядро за 20 ₽», «разложи фразы по страницам», «дай минус-слова для Директа». Перед каждым платным вызовом агент видит смету, а жесткий предел трат задаете вы.

Мутаген для кода. Тот же пакет — это CLI `mutagen-ru` и типизированная библиотека для Node.js. Ядро можно пересобирать по расписанию в GitHub Actions или cron, выгружать в CSV, XLSX и JSON, складывать в базу и получать pull request с новыми фразами раз в неделю. Кэш, журнал задач и лимит бюджета работают одинаково в MCP, CLI и библиотеке.

## Быстрый старт

Нужен Node.js 22.12 или новее.

### 1. Ключ API

1. Зарегистрируйтесь на [mutagen.ru](https://mutagen.ru/?r=94674) (партнерская ссылка автора проекта; обычная регистрация — на https://mutagen.ru).
2. Возьмите ключ в кабинете: https://mutagen.ru/?api_config. Там же включите «Разрешить подключение только с ip» — API работает только по HTTP, см. [ограничения](#ограничения-и-честные-оговорки).
3. Пополните баланс. Парсер Вордстата и проверка конкуренции списываются с баланса (от 0,02 ₽ за запрос). Отчеты Мега-инструмента через API доступны только с подпиской: [тарифы](https://mutagen.ru/serp/?tarif).

### 2. Проверка

```bash
export MUTAGEN_API_KEY=ваш_ключ
npx -y -p mutagen-ru-mcp mutagen-ru balance
```

Баланс бесплатный. Если ответ пришел, ключ работает.

MCP-сервер запускается так: `npx -y mutagen-ru-mcp`. Обычно его запускает сам клиент, команда ниже уже вписана в конфиги.

### 3. Подключение к нейросети

Во всех примерах `MUTAGEN_BUDGET_RUB` — предел трат в рублях на весь процесс MCP-сервера (пока клиент его не перезапустит). Без него действует 50 ₽.

**Сервер по HTTP.** Для клиентов, которые подключаются по адресу, есть Streamable HTTP:

```bash
MUTAGEN_API_KEY=ваш_ключ npx -y mutagen-ru-mcp --http --port 3333
# адрес для клиента: http://127.0.0.1:3333/mcp
```

Если слушать не localhost (`--host 0.0.0.0`), обязателен токен `MUTAGEN_MCP_HTTP_TOKEN`: клиент передает его в заголовке `Authorization: Bearer ...`. Запросы из браузера с заголовком `Origin` сервер принимает только с localhost; другие адреса перечислите через запятую в `MUTAGEN_MCP_ALLOWED_ORIGINS`. Бюджет `MUTAGEN_BUDGET_RUB` общий для всех HTTP-сессий процесса.

## Что можно делать

Ниже — запросы, как их пишут в чате, инструменты, которые вызовет агент, и что получится. Ниша для примеров — натяжные потолки, регион Вордстата — Россия (225). Где написано «живой ответ», это настоящий результат запроса к Мутагену от 14.10.2026, сокращенный до первых строк. Где написано «пример», таблица показывает форму ответа, а цифры условные.

Цены взяты из живой проверки 14.10.2026: частота 0,02 ₽ за фразу и вид, «Ключи Вордстата» 0,02 ₽ (200 фраз) или 0,20 ₽ (2000 фраз), конкуренция 0,30 ₽ за фразу. Отчеты Мега-инструмента денег не списывают, но требуют подписку и расходуют суточную квоту запросов.

### 1. Собрать семантическое ядро для нового сайта или раздела

> Собери семантическое ядро для раздела «натяжные потолки» по маркерам «натяжные потолки» и «потолки под ключ». Бюджет 15 рублей, регион Россия.

Агент: `mutagen_build_core` с `dry_run: true` → показывает смету → после вашего «да» тот же вызов без `dry_run`. Сценарий собирает хвосты маркеров, убирает дубли и явный мусор («скачать», «вакансии», «б/у» и т. п.), снимает точную частоту `"!фраза"` и группирует фразы в кластеры. MCP-prompt `build-core` ведет агента по этим шагам.

Смета — живой ответ `--dry-run` для двух маркеров:

| Шаг | Метод | Единиц | Сумма |
|---|---|---|---|
| Хвосты маркеров (200 фраз) | `parser.get`, `wordstat_key_50` | 2 | 0,04 ₽ |
| Точная частота | `parser.mass.new`, `wordstat_qs` | 500 | 10,00 ₽ |
| **Итого** | | | **10,04 ₽** |

Если бюджет меньше сметы, план уменьшается до бюджета: при 1,5 ₽ сценарий честно пишет «план уменьшен: max_phrases 500 → 73». Результат — таблица и файл (пример):

| Фраза | Базовая частота | "!Точная" | Кластер | Маркер |
|---|---|---|---|---|
| натяжной потолок цена | 55 926 | 1 011 | натяжной потолок цена | натяжные потолки |
| сколько стоит натяжной потолок | 18 667 | 1 382 | сколько стоит натяжной потолок | натяжные потолки |
| … | | | | |

Цена: по смете, не больше `budget_rub`. CLI: `mutagen-ru core "натяжные потолки" "потолки под ключ" --budget 15 -o core.xlsx`.

### 2. Расширить ядро хвостами и подсказками

> Вот наше ядро (core.csv). Найди новые фразы, которых в нем еще нет, бюджет 5 рублей.

Агент: `mutagen_expand_core` (маркеры по умолчанию — главные фразы кластеров) или `mutagen_wordstat_keywords` по одной фразе. Живой ответ «Ключи Вордстата», 200 фраз, 0,02 ₽:

| Фраза | Частотность |
|---|---|
| натяжной потолок | 1 073 667 |
| потолок под натяжной потолок | 56 753 |
| натяжной потолок цена | 55 926 |
| установка натяжных потолков | 52 489 |
| натяжные потолки фото | 40 119 |
| натяжной потолок своими руками | 32 939 |
| … еще 194 строки | |

С подпиской Мега-инструмента `source: "serp"` берет хвосты из базы Мутагена (`report_keyword_tailings`), без подписки — из Вордстата. `source: "auto"` выбирает сам. CLI: `mutagen-ru keywords "натяжные потолки" --depth 200 -o tails.csv`, `mutagen-ru expand -i core.csv --budget 5`.

### 3. Снять базовую и точную частоту, оценить конкуренцию

> Сними базовую и точную частоту по этим четырем фразам. Потом проверь конкуренцию у двух самых частотных.

Агент: `mutagen_frequency` с `types: ["wordstat_n", "wordstat_qs"]`, затем `mutagen_competition`. Живой ответ, 4 фразы × 2 вида = 0,16 ₽:

| Фраза | Базовая | "!Точная" |
|---|---|---|
| натяжной потолок цена | 62 529 | 1 011 |
| установка натяжных потолков | 54 907 | 593 |
| натяжной потолок купить | 27 870 | 694 |
| сколько стоит натяжной потолок | 20 422 | 1 382 |

Доступны все виды частотности Вордстата: базовая `n`, "фразовая" `q`, "!точная" `qs`, [порядок] `no`, "[порядок]" `qo`, "[!точный порядок]" `qso`. Конкуренция — шкала Мутагена 0–25 (ниже 5 — низкая), плюс частота в кавычках, число хвостов, ставки Директа и витальный сайт (пример):

| Фраза | Конкуренция (0–25) | Частота "в кавычках" | Хвосты |
|---|---|---|---|
| натяжной потолок цена | 12 | 4 800 | 950 |

Цена: частота 0,02 ₽ × фраза × вид, конкуренция 0,30 ₽ × фраза, повтор той же фразы в течение 7 дней бесплатный. Конкуренция зависит от связи Мутагена с Яндекс Директом и может считаться очень долго, см. [ограничения](#ограничения-и-честные-оговорки). CLI: `mutagen-ru freq -t n,qs -i phrases.txt`, `mutagen-ru competition -i top.txt`.

### 4. Кластеризовать фразы и разложить их по страницам

> Разложи фразы из tails.csv по страницам: какие фразы вести на одну страницу.

Агент: `mutagen_cluster`. Три режима:

- `lexical` — бесплатно и без обращения к API: группировка по общим словам с учетом словоформ (стеммер Snowball);
- `serp` — по совпадению URL в топе выдачи, как кластеризация на сайте Мутагена; нужна подписка, 1 запрос квоты на фразу, до 300 фраз;
- `project` — забрать готовые кластеры проекта «Избранного» по его id (бесплатно).

Живой ответ, `lexical`, 40 фраз, бесплатно (сокращено):

| Кластер | Фраза | Частота |
|---|---|---|
| натяжной потолок цена | натяжной потолок цена | 55 926 |
| натяжной потолок цена | стоимость натяжного потолка | 11 164 |
| натяжной потолок цена | натяжной потолок цена за м2 | 4 421 |
| точечные светильники для натяжного потолка | точечные светильники для натяжного потолка | 5 767 |
| точечные светильники для натяжного потолка | встраиваемый светильник в натяжной потолок | 3 499 |
| натяжные потолки скрытый карниз | скрытый карниз в натяжном потолке | 3 650 |

Лексическая группировка грубая: фразы с одинаковыми словами она объединяет, даже если интент разный (в живом прогоне «светильники» и «монтаж» попали в кластер «цена»). Для раскладки по страницам точнее режим `serp`. CLI: `mutagen-ru cluster -i tails.csv`, `mutagen-ru cluster --mode serp -i tails.csv`.

### 5. Выбрать Title, H1 и Description по частотам

> Предложи Title, H1 и Description для страницы цен на натяжные потолки по этим фразам.

Агент: `mutagen_title_h1`. Если у фраз уже есть частоты, это бесплатно. Если нет, сценарий снимет точную частоту: 0,02 ₽ за фразу. Живой ответ на 15 фраз кластера «цена»:

| Элемент | Текст | Обоснование |
|---|---|---|
| Title | Натяжной потолок цена — с установкой, за метр | главная фраза «натяжной потолок цена» (55 926) + хвосты фраз «потолок натяжной цена с установкой» (21 548) и «натяжной потолок цена за метр» (6 884) |
| H1 | Потолок натяжной цена с установкой | вторая по частоте формулировка (21 548) |
| Description | Натяжной потолок цена: с установкой, за метр. Узнайте подробнее на сайте! | главная фраза + те же уточнения + призыв |

Слова не склоняются: уточнения берутся целыми фразами кластера или их хвостами в том виде, в каком они есть в Вордстате, поэтому заготовка не собирает слова разных фраз в одну неграмотную группу. Город добавляется через запятую. Это заготовка с обоснованием по частотам, а не готовый текст: ее правит редактор. Параметры `brand` и `city` добавляют бренд и город. CLI: `mutagen-ru title -i price.csv --city Москва`.

### 6. Найти фразы, по которым нет страницы

> Какие запросы конкурентов из топа есть у них и нет у нашего сайта example.ru?

С подпиской агент вызовет `mutagen_content_gap`: ключи вашего домена и 5 конкурентов (их Мутаген находит сам, или задайте `competitors`), разница — фразы, по которым у вас нет страницы. Цена: 1 запрос квоты на домен. Пример:

| Фраза | Частота | Конкурентов | Лучшая позиция | Лучший конкурент |
|---|---|---|---|---|
| натяжной потолок в ванной | 17 610 | 3 | 2 | a.ru |

Без подписки: выгрузите список фраз, под которые у вас уже есть страницы (`pages.txt`), и сравните его с ядром бесплатной локальной операцией:

```bash
mutagen-ru text compare -i pages.txt -i core.csv --implicit
```

Строки с `only_b` — фразы ядра без страницы. `--implicit` считает одинаковыми фразы, которые отличаются только формой слов или порядком.

### 7. Проверить позиции

> На каких позициях example.ru по запросам про натяжные потолки?

Агент: `mutagen_domain_report` с `report_keywords_organic` (ключи и позиции домена) или `mutagen_keyword_report` с `report_keyword_positions_organic` (топ-50 по фразе). Нужна подписка, 1 запрос квоты. Пример (колонки отчета Мутагена):

| keyword | position | region_wsn | page |
|---|---|---|---|
| натяжные потолки под ключ | 7 | 3 100 | https://example.ru/catalog/ |

Честно: это позиции из базы Мутагена, которую он обновляет периодически, а не съем выдачи в реальном времени. В API нет инструмента, который проверит позицию прямо сейчас. Бесплатной альтернативы внутри Мутагена нет. Позиции своего сайта можно смотреть в Яндекс Вебмастере.

### 8. Подготовить ядро для Директа: минус-слова

> Подготовь минус-слова для кампании по натяжным потолкам.

Агент: `mutagen_minus_words` (MCP-prompt `direct-prep`). По готовому списку фраз — бесплатно, по маркерам — сначала собирает «Ключи Вордстата» (0,02 ₽ за маркер). Живой ответ на 200 фраз, бесплатно:

```text
-своими -руками -видео -фото -как -сделать -самостоятельно -авито
```

| Слово | Категория | Спорно | Фраз | Сумма частот |
|---|---|---|---|---|
| своими руками | Своими руками | нет | 9 | 65 594 |
| фото | Фото и видео | нет | 3 | 45 175 |
| работа | Работа и вакансии | да | 1 | 9 173 |
| отзывы | Отзывы и обсуждения (спорно) | да | 1 | 7 130 |

Спорные слова в строку не попадают: решение за вами (`include_disputed` или `--disputed` добавит их). Ставки и прогноз Директа — `mutagen_direct_bids`, 0,02 ₽ за фразу, но сейчас этот сбор может идти очень долго, см. [ограничения](#ограничения-и-честные-оговорки). CLI: `mutagen-ru minus -i tails.csv`, `mutagen-ru minus "натяжные потолки" --budget 1`.

### 9. Сравнить с конкурентами

> Кто конкуренты example.ru в выдаче и по каким запросам они нас обходят?

Агент: `mutagen_domain_report` с `report_domain_competitors` (конкуренты по пересечению ключей), затем `report_keywords_organic` по конкуренту и `mutagen_content_gap`. Все это — отчеты Мега-инструмента: нужна подписка, 1 запрос квоты на отчет. Пример (колонки отчета Мутагена):

| domain | visibility | domain_organic_keywords |
|---|---|---|
| a.ru | 41,2 | 5 600 |

Без подписки: соберите ядро по маркерам, которые продвигает конкурент (`mutagen_build_core`), и сравните его со своим списком через `mutagen_text` с операцией `compare`.

### 10. Составить контент-план статей по ядру

> Составь контент-план информационных статей по этим фразам.

### Выгрузка в CSV, XLSX, JSON

У любой команды CLI есть `-o файл.csv|.xlsx|.json|.ndjson`, у любого инструмента MCP — `save_as`. Файлы MCP ложатся только в каталог `MUTAGEN_OUTPUT_DIR` (по умолчанию `./mutagen-results`): относительный `save_as` считается от него, путь наружу (`..`, ссылки) отклоняется. В конце каждого файла есть строка «Данные: Мутаген (mutagen.ru)» (в XLSX — лист «Источник»): этого требуют условия API Мутагена.

### Скрипт на Node

Библиотека экспортирует то же, на чем работают CLI и MCP: клиент API (`MutagenClient`), сессию с бюджетом, кэшем и журналом (`MutagenSession`), сценарии (`buildCore`, `expandCore`, кластеризация, минус-слова и другие), локальную обработку фраз и выгрузку (`writeTable`). Полный пример — [examples/node/build-core.mjs](examples/node/build-core.mjs):

```js
import { BudgetError, buildCore, loadConfig, MutagenSession, writeTable } from "mutagen-ru-mcp";

const session = MutagenSession.fromConfig(loadConfig()); // ключ и бюджет из переменных окружения
const params = { seeds: ["натяжные потолки"], budgetRub: 15 };

let result;
try {
  result = await buildCore(session, params);
} catch (error) {
  if (!(error instanceof BudgetError) || error.kind !== "needs_confirmation") throw error;
  // Смета выше MUTAGEN_AUTO_APPROVE_RUB: подтверждаем ее токеном из ошибки.
  result = await buildCore(session, params, { confirmToken: error.confirmToken });
}
await writeTable(result.table, "core.xlsx");
```

## Как экономить

- **Смета до трат.** `--dry-run` в CLI и `dry_run: true` в MCP показывают план и цену без обращения к API. `mutagen_estimate` и `mutagen-ru estimate` считают смету любого плана: `mutagen-ru estimate --freq 500 -t n,qs --competition 50` → 35,00 ₽.
- **Лимит бюджета.** `MUTAGEN_BUDGET_RUB` (по умолчанию 50 ₽) — жесткий предел трат на один запуск CLI или на весь процесс MCP-сервера: все его сессии, в том числе HTTP, тратят один общий бюджет до перезапуска. Вызов, который в него не помещается, отклоняется до обращения к API. `--budget N` в CLI ограничивает один запуск. Сценарии с бюджетом уменьшают план так, чтобы в него уложиться.
- **Порог подтверждения.** Вызовы до `MUTAGEN_AUTO_APPROVE_RUB` (по умолчанию 1 ₽) идут без вопросов. Дороже — CLI спрашивает «Продолжить?» или ждет `--yes`, а MCP возвращает смету и `confirm_token`. Если клиент умеет спрашивать человека через свой интерфейс (elicitation), подтверждение спрашивается у вас.
- **Режим «только бесплатное».** `MUTAGEN_FREE_ONLY=1` или `--free-only`: любой платный вызов отклоняется, бесплатные (баланс, массовые задания, локальная обработка) работают.
- **Кэш.** Готовые частоты и конкуренция хранятся 7 дней, отчеты Мега-инструмента — 1 день (`MUTAGEN_CACHE_TTL_*_DAYS`). Повторный запрос из кэша бесплатный. Баланс и статусы задач не кэшируются. Обойти кэш: `--refresh` или `force_refresh`, отключить: `--no-cache` или `MUTAGEN_NO_CACHE=1`.
- **Журнал и бесплатные повторы.** Каждая платная задача пишется в журнал. Если ответ потерялся или задача еще считается, повтор того же вызова подхватывает уже оплаченную задачу и не платит второй раз. MCP ждет результат около 45 секунд, потом отвечает `processing`; повторите вызов позже — это бесплатно. Новую платную задачу вместо зависшей создает `--new-task` или `new_task: true`.
- **Меньше инструментов — меньше контекста.** Описания и схемы всех 22 инструментов занимают около 34 тыс. символов контекста агента. `MUTAGEN_TOOLS` оставляет только нужные группы: например, `basic,parser,text` — около 14 тыс. символов. Группы: `basic`, `parser`, `serp`, `scenarios`, `text`.
- **Большие результаты — в файл.** MCP отдает агенту сводку и первые строки, полный результат — в файл `save_as`. `fields` и `limit` убирают лишние колонки и строки, например 30 колонок прогноза Директа.
- **Своя обработка бесплатна.** Дубли, неявные дубли, словарь, фильтр по словам, лексическая кластеризация, минус-слова и контент-план по готовому списку работают локально, без ключа и без денег.

## Ограничения и честные оговорки

- **API только по HTTP.** HTTPS у `api.mutagen.ru` нет, ключ уходит по сети открытым текстом в адресе запроса. Включите в кабинете белый список IP («Разрешить подключение только с ip»): тогда украденный ключ не сработает с чужого адреса. В наших логах, ошибках и файлах ключ заменяется на `***`.
- **Отчеты Мега-инструмента — только по подписке.** Хвосты из базы, вопросы, LSI, позиции, ключи сайтов и страниц, конкуренты, кластеризация по выдаче и поиск пробелов без подписки возвращают «нужна подписка» (ошибка 111). Вместе с ошибкой агент получает подсказку, чем заменить отчет без подписки.
- **Лимиты подписки.** Отчеты расходуют суточную квоту запросов, а строки в отчете и выгрузки за месяц ограничены тарифом. По сайту на 14.10.2026: «Простой» — 950 ₽ в месяц, 300 запросов в сутки, 20 000 строк в отчете; «Расширенный» — 1 250 ₽, 1 500 запросов; «Продвинутый» — 2 450 ₽, 6 000 запросов. Актуально — на [странице тарифов](https://mutagen.ru/serp/?tarif). Когда квота кончается, Мутаген отвечает ошибкой 112.
- **Нет списка проектов «Избранного».** Метода в API нет, хотя он описан в документации. Ключи проекта доступны по id, а id берется из адреса страницы проекта в кабинете (Избранное → проект). Создавать проекты и добавлять в них ключи через API нельзя.
- **Нет правой колонки Вордстата.** «Ключи Вордстата» отдают только левую колонку: 200 или 2000 фраз.
- **Конкуренция и ставки Директа могут висеть.** Оба сбора зависят от связи Мутагена с Яндекс Директом. В октябре 2026 года они считались больше 40 минут. Деньги списываются при постановке задачи; повторный опрос бесплатный, и повтор того же вызова подхватывает уже оплаченную задачу. Если задача висит больше 2 часов, ответ прямо говорит о вероятном сбое на стороне Мутагена или Директа и советует проверить кабинет или написать в поддержку. Конкуренция считается без учета региона — так и на сайте Мутагена.
- **Частоты Вордстата приблизительны и меняются.** Это оценка Яндекса, она плавает от месяца к месяцу. Разные способы сбора дают разные числа: в живой проверке «натяжной потолок цена» в левой колонке Вордстата — 55 926, а отдельным запросом базовой частоты — 62 529. Сравнивайте фразы, собранные одним способом.
- **Позиции — из базы Мутагена.** Это не съем выдачи в реальном времени: база обновляется периодически.
- **Подтверждение через агента — защита от случайности, а не от злого умысла.** Если клиент MCP не умеет спрашивать человека, `confirm_token` получает сам агент и может подтвердить смету без вас. Жесткий предел — только `MUTAGEN_BUDGET_RUB`. Ставьте его таким, какой не жалко потерять.
- **Функций сайта, которых нет в API, у нас тоже нет.** Мы не автоматизируем веб-интерфейс Мутагена: только официальный API и локальная обработка. Рейтинги сайтов, создание проектов, кластеризация на стороне Мутагена недоступны.

## FAQ

**Это официальный клиент Мутагена?**
Нет. Это независимый проект с открытым кодом, он не связан с Мутагеном. Данные принадлежат Мутагену, в каждом ответе и файле стоит пометка «Данные: Мутаген (mutagen.ru)».

**Нужна ли подписка?**
Для частот, «Ключей Вордстата», конкуренции, ставок Директа и всех локальных операций — нет, хватит баланса. Подписка нужна для отчетов Мега-инструмента: хвостов из базы, позиций, ключей сайтов, конкурентов, кластеризации по выдаче.

**Сколько стоит собрать ядро?**
Два маркера, по 200 хвостов, точная частота для 500 фраз — 10,04 ₽. Проверка конкуренции для топ-20 фраз добавит 6 ₽. Точную смету для своих параметров покажет `--dry-run`.

**Что работает без ключа?**
`mutagen_text` и `mutagen-ru text`, лексическая кластеризация, минус-слова и контент-план по готовому списку фраз, Title и H1 по фразам с частотами. Они не обращаются к API.

**Агент может потратить все деньги?**
Не больше `MUTAGEN_BUDGET_RUB` за запуск CLI или за время работы MCP-сервера. Каждый вызов дороже `MUTAGEN_AUTO_APPROVE_RUB` требует подтверждения. Для полной уверенности включите `MUTAGEN_FREE_ONLY=1`.

**Конкуренция ответила `processing`. Деньги списаны?**
Да, при постановке задачи. Повторите тот же вызов позже: он найдет задачу в журнале и не заплатит второй раз.

**Почему частоты отличаются от того, что я вижу в Вордстате?**
Вордстат показывает оценку, которая меняется, а разные виды частотности и способы сбора дают разные числа. См. [ограничения](#ограничения-и-честные-оговорки).

**Как подключить к клиенту, которого нет в списке?**
Любой MCP-клиент со stdio запускает сервер командой `npx -y mutagen-ru-mcp` с переменной `MUTAGEN_API_KEY`. Клиентам, которые подключаются по адресу, подойдет `npx -y mutagen-ru-mcp --http`.
