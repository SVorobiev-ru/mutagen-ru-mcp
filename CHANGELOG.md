## [0.1.0] — 2026-10-14

Первый выпуск.

### Added

- Клиент API Мутагена для Node.js (`MutagenClient`): баланс, ключи проекта «Избранного», проверка конкуренции, парсер Вордстата и Директа (все 6 видов частотности, «Ключи Вордстата» 200 и 2000, ставки Директа), массовые задания, 24 отчета Мега-инструмента с фильтрами. Ошибки 100–118 с подсказками на русском и английском, ограничение частоты запросов, опрос долгих задач с таймаутом и отменой.
- Защита от трат: смета до вызова, бюджет сессии (`MUTAGEN_BUDGET_RUB`), порог подтверждения (`MUTAGEN_AUTO_APPROVE_RUB`), режим «только бесплатное» (`MUTAGEN_FREE_ONLY`), проверка баланса перед дорогими вызовами.
- Журнал платных задач: повтор того же запроса подхватывает оплаченную задачу и не платит второй раз.
- Файловый кэш готовых результатов: частоты и конкуренция — 7 дней, отчеты — 1 день.
- Выгрузка в CSV (для русского Excel), JSON, NDJSON и XLSX с пометкой об источнике данных.
- Локальная обработка фраз без API: дубли и неявные дубли, словарь, комбинатор, сравнение списков, фильтр, вопросы, подсчет; лексическая кластеризация на стеммере Snowball.
- Сценарии: семантическое ядро в пределах бюджета, расширение ядра, кластеризация (лексическая, по выдаче, из «Избранного»), Title, H1 и Description по частотам (без склонения: уточнения — целые фразы кластера или их хвосты в исходной форме), фразы конкурентов без страницы, минус-слова для Директа, контент-план из вопросов.
- CLI `mutagen-ru`: 18 команд, `--dry-run`, `--yes`, `--budget`, `--free-only`, выгрузка `-o`, коды выхода для CI.
- MCP-сервер `mutagen-ru-mcp`: 22 инструмента в 5 группах (`MUTAGEN_TOOLS`), 3 справочных ресурса, 4 prompts, транспорты stdio и Streamable HTTP, подтверждение трат через elicitation или `confirm_token`.
- Живые тесты на реальном API по флагу: `MUTAGEN_LIVE=1 npm run test:live`, не дороже 2 ₽ за прогон, не входят в `npm test` и CI.
- Примеры: конфиги MCP-клиентов, скрипт на Node, GitHub Actions (сбор по расписанию и PR с новыми фразами), cron, Google Таблицы, SQLite.
